# Spec: 18-i18n

**Goal:** Provide compile-time, type-safe, reactive translation and enforcement for UI strings.
**Package/app(s):** `apps/web`
**Depends on:** `08-web-editor`, `15-auth-multi-tenant`

## Inputs

- Locale JSON catalogs at `apps/web/messages/{en,es,fr,it}.json`.
- Browser request headers (`Accept-Language`) and cookies (`preferredLanguage`) for locale negotiation.

## Outputs

- Compiled type-safe translation modules in `apps/web/src/lib/paraglide/*`.
- Svelte layout and page structures rendered in the resolved language.
- Static linter validation errors in `pnpm lint` via `scripts/check-i18n.js` if unlocalized templates or attributes are detected.

## In scope

- **Type-Safe Compilation**: Compiling message keys from JSON files into auto-generated TypeScript functions using Paraglide JS.
- **Locale Negotiation**: Negotiating preferred languages in `hooks.server.ts` and SvelteKit loads, supporting cookies (`preferredLanguage`), browser language preferences, and query strings.
- **Reactive UI updates**: Subscribing to language changes reactively using Svelte layout stores/contexts and Paraglide's runtime.
- **Static Analysis Linter**: Running a custom Node script (`scripts/check-i18n.js`) in `pnpm lint` to scan Svelte markup for hardcoded user-facing strings, enforcing translation key usage and matching locale keys across translation files.

## Out of scope

- **Dynamic Data Translation**: Translating database rows (e.g., instructions generated by AI or edited by humans).
- **Runtime External Translation**: Using third-party machine translation APIs (like Google Cloud Translation or Gemini) dynamically on the frontend.
- **Translating System Logs**: Localizing server-side engine logs or worker diagnostics.

## Acceptance criteria

- **Compile-Time Safety**: Translation strings are resolved via `m.keyName()`. References to non-existent keys fail compilation.
- **Locale Syncing**: All locale JSON files must define the exact same set of translation keys. Extraneous or missing keys must fail the build/lint.
- **Static Linter Guard**: The static linter (`scripts/check-i18n.js`) fails with a non-zero exit code if it finds raw hardcoded text nodes or unlocalized attributes (`placeholder`, `title`, `alt`) outside Svelte expressions `{...}`.
- **Standard UI Localization**: Pages (landing page, editor, login, register, reset-password) resolve and display translated labels and placeholders based on the current locale.

## Validation

- Run typechecks to verify Paraglide imports compile cleanly:
  ```bash
  pnpm --filter @vitruvius/web typecheck
  ```
- Run linter to execute static i18n checks:
  ```bash
  pnpm --filter @vitruvius/web lint
  ```
